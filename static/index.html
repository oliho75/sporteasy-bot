Mode d'emploi

Poser tes options

Tape sur un créneau :

  • 1× Priorité : le créneau que tu veux.
  • 2× Fallback : ton plan B le même jour.
  • 3× Retiré.

Taper un créneau où tu es déjà inscrit (barre verte) ou en liste d'attente (barre orange) te propose de te désinscrire, avec confirmation.

En haut de l'écran, Mes options résume ce que le bot a en main ; tape une ligne pour retrouver le créneau.

Le fallback

C'est un plan B, jour par jour. Si ta priorité du jour est réservée, le bot n'y touche pas. Si tu la rates, il prend le fallback. Et si la priorité passe finalement (liste d'attente), il libère le fallback tout seul.

Quand le bot réserve

Chaque créneau a sa propre heure d'ouverture, lue sur Sporteasy (« ouvre sam. 24 à 20h30 »). Le bot attend ensuite un petit délai aléatoire pour ne pas être toujours premier pile à la seconde :

  • Lundi : quelques secondes
  • Jeudi : moins d'une minute
  • Autres jours : 1 à 5 min

Réglable dans Réglages sur ordinateur.

Les statuts

  • priorité / fallback : option posée, pas encore traitée.
  • programmé : le bot connaît l'heure d'ouverture et attend.
  • ouvert · attente : c'est ouvert, il laisse passer le délai.
  • réservé : c'est dans la poche.
  • liste d'attente : complet, tu es dans la file. Si une place se libère, tu reçois une notif.
  • ignoré : quota de la semaine atteint, ou ta priorité du jour est déjà réservée.
  • erreur : la réservation n'est pas passée. Le bot réessaie tout seul ; le détail est dans le journal.
  • annulé : le club a annulé ou supprimé le créneau.

Le switch en haut

Vert = le bot tourne. Gris = en pause, il ne réserve rien.

Notifications

Installe l'app ntfy, abonne-toi au canal ci-dessous (nom exact), et tu reçois une notif à chaque réservation, liste d'attente, place libérée, créneau annulé ou erreur. Une seule notif par événement.
